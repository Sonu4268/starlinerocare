## ⚡ How to Deploy to Vercel (1-Click or Git)

### Method 1: Using GitHub + Vercel (Recommended)
1. Unzip the project folder `starline-ro-care.zip`.
2. Push the files to a new GitHub repository (e.g. `starline-ro-care` or `starline`).
3. Open [Vercel Dashboard](https://vercel.com/new).
4. Select the repository and click **Deploy**.
5. Set your project name as `starline` (or `starline-ro-care`).
6. Your website will be live in 60 seconds with a free `.vercel.app` domain and free SSL!

### Method 2: Deploy using Vercel CLI
```bash
npm install -g vercel
cd starline-ro-care
vercel
```
Follow the simple terminal prompts to deploy immediately.
